# Lumen

Lumen — приложение для macOS: чат с моделями Claude и ChatGPT, агент, который работает в папке проекта, память между разговорами и боты под отдельные роли.

Модели подключаются через подписку Claude Code (официальный `claude`), ключ Anthropic API или подписку ChatGPT (официальный `codex`). Интерфейс написан на SwiftUI.

## Возможности

- **Чат** с Claude и ChatGPT: выбор модели и глубины размышления, ответ печатается по ходу, «Стоп» прерывает сразу. Справа — окно контекста и расход.
- **Агент** работает в выбранной папке: читает файлы, правит их, запускает команды. Шаги видны по ходу. Коммит возможен, push — только с твоего подтверждения.
- **Память.** Lumen запоминает важное и использует его в других разговорах. Факты можно закрепить, изменить или забыть; есть поиск по прошлым разговорам.
- **Проекты** с инструкциями и файлами, которые видит каждый разговор проекта.
- **Боты.** Агенты с одной ролью, их зовут через `@id`. Права бота задаёт пользователь, всё запрещённое в коде просто недоступно боту.
- **Навыки** в формате SKILL.md: свои, из каталога или по ссылке на GitHub.
- **Браузер сбоку** (⇧⌘B). Агент и боты открывают страницы, нажимают, вводят текст и делают снимки. Ссылки из переписки открываются здесь же.
- **Импорт из Claude Code.** Разговоры и проекты переносятся и продолжаются с того же места.

## Требования

- macOS 14 или новее.
- Для подписки Claude — установленный [Claude Code](https://claude.com/claude-code) версии 2.1.280 или новее (`claude update`).
- Для ChatGPT — `npm install -g @openai/codex` и вход в Настройках.
- Для сборки из исходников — Xcode или Command Line Tools с Swift 6.1.

## Установка

Скачай `Lumen-*.zip` со страницы [Releases](https://github.com/romankandeevy/lumen/releases), распакуй и перетащи `Lumen.app` в «Программы». Приложение не нотаризовано: при первом запуске открой его через правый щелчок → «Открыть».

## Сборка из исходников

```bash
./build.sh          # собрать build/Lumen.app
./build.sh run      # собрать и открыть
./build.sh install  # собрать, положить в «Программы» и открыть
./build.sh test     # тесты
```

Живые проверки на настоящем `claude` тратят лимит подписки, поэтому по умолчанию выключены: `LUMEN_LIVE=1 ./build.sh test`.

Для проверки без своих данных можно указать другую папку хранения:

```bash
open -n --env LUMEN_HOME=/tmp/lumen-test build/Lumen.app
```

Данные по умолчанию лежат в `~/Library/Application Support/Lumen`, ключ API — в Связке ключей.

## Структура

- `Sources/LumenCore` — модели и общие типы.
- `Sources/LumenStorage` — база данных (GRDB), миграции, память.
- `Sources/LumenProviders` — `claude` и `codex`, Связка ключей, браузерный сокет, MCP.
- `Sources/LumenUI` — интерфейс (SwiftUI).
- `Sources/lumen-mcp` — MCP-сервер памяти, навыков и вызова ботов. Он лежит в бандле и его запускают `claude` и `codex`.
- `ui/` — React-макет экранов. В приложение не входит.
