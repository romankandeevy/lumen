# Claude Chat

Отдельное приложение: чат с Claude Code, который знает проекты в `~/Documents/prog`, память и Пульт.
Выбор модели и «сколько думать» (Низкий … Ультракод), чаты, контекст, окно контекста, расход,
задачи в фоне — в одном окне.

Сейчас это **только макет** (React + Vite + shadcn, тёмный монохром как у Пульта). Приложение будет
на Swift/SwiftUI, когда макет утверждён.

Вынесено из Пульта (`Мак-приложения/prog-dashboard`, вкладка «Claude») 15.10.2026 без изменений в виде.
Быстрая задача и «Claude в фоне» остаются в Пульте.

## Макет

```bash
cd ui && npm install && npm run dev -- --port 5175
```

Открыть http://localhost:5175. Скриншоты — в `mockups/`.
