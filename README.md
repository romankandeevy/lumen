# Lumen

Mac-приложение по логике Hermes Agent, но красивое. Внешне — смесь Claude Code и Cursor.
Думает через подписку Claude Code или через Anthropic API. Codex и OpenAI подключим позже.

Сейчас это **только макет** (React + Vite + shadcn), в нём нажимается каждая кнопка. Само приложение будет на Swift/SwiftUI, когда макет утвердят.

## Как устроено

Наверху боковой панели три вкладки, как у Claude:

- **Чат** — просто разговор. Выбираешь модель и «сколько думать», можно поговорить голосом. Lumen ничего не трогает.
- **Агент** — работа в папке проекта. Папка и место работы (Этот Мак или облако Claude Code) выбираются в поле ввода. Облачные сессии помечены облачком.
- **Боты** — агенты-субагенты под одну роль. Из любого чата бота зовут через `@id`, и Lumen передаёт ему задачу. Всё, что вне роли, отрезано в коде: у бота просто нет нужного инструмента. У каждого бота один постоянный чат, старое сжимается в пересказы. Свой цвет и квадратный знак отличают бота от круглой сферы Lumen.

Внизу панели общее для всех вкладок: **Память** (факты, граф связей, прошлые разговоры), **Люди** (анкеты о близких), **Характер** (как отвечает, живое превью), **Инструменты** (навыки, MCP, коннекторы, API), **Настройки** (внешний вид, модели и оплата, голос, клавиши, данные).

Кнопка «+» в поле ввода включает поиск в интернете, глубокое исследование и память, прикрепляет файл и зовёт бота.

## Макет

```bash
cd ui && npm install && npm run dev -- --port 5175
```

Открыть http://localhost:5175. Скриншоты лежат в `mockups/`.
