# Lumen

Mac-приложение по логике Hermes Agent, но красивое: смесь Claude Code и Cursor. Lumen разговаривает, работает в папках проектов, помнит тебя между разговорами, держит ботов под отдельные роли и учится на своих задачах.

Думает через подписку Claude Code (официальный `claude`), через ключ Anthropic API или через подписку ChatGPT (официальный `codex`). Интерфейс — Swift/SwiftUI. В окне только то, что уже работает.

## Что умеет

- **Чат.** Модели Claude (Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 5.5) и ChatGPT (GPT-6 Astra, GPT-6.1 Sol, GPT-6 Luna), «сколько думать», ответ печатается по ходу, «Стоп» — сразу. Справа — окно контекста, «Сжать разговор», лимиты подписки и расход по API с месячным пределом.
- **Агент.** Работает в выбранной папке: читает, правит, запускает команды; шаги видны по ходу, план — сбоку, в конце — «что дальше». «Изменения»: разница по файлам, откатить (в Корзину), закоммитить. **Push только с твоего OK** — агент не может его запустить.
- **Память.** Lumen сам запоминает важное («Запомнил») и опирается на это в других чатах («Опирался на»). Страница «Что Lumen знает»: факты (закрепить, изменить, забыть), **граф** как в Obsidian, поиск по прошлым разговорам с русскими окончаниями.
- **Проекты.** Как в Claude: свои инструкции и файлы, которые видит каждый разговор проекта; папка для агента.
- **Боты.** Агенты под одну роль: зовёшь из любого чата через `@id`, у каждого один постоянный разговор. Права выбираешь ты, и всё, чего не разрешено, **отрезано в коде** — у бота нет такого инструмента (без права правки он не изменит файл ни правкой, ни командой). Бот настраивается по одной фразе, может позвать другого бота (один шаг), у него свои навыки, и он записывает, **чему научился** на прошлых задачах.
- **Навыки.** Формат SKILL.md (agentskills.io). Свои, каталог Anthropic, установка по ссылке GitHub — уже стоящий навык заново не качается, подозрительный ставится выключенным. Модель видит список включённых навыков и сама берёт нужный — в чате, у агента, у ботов. «Написать с Lumen»: черновик → перечитать свежим взглядом → проверка по стандарту. После большой задачи Lumen сам предлагает навык («Сам научился»).
- **Ещё:** свои меню с буквами-клавишами, поиск ⌘K, закреп и переименование разговоров, две тёмные темы, ширина переписки, «Меньше движения», автообновление (стабильные версии, бета по желанию). В покое Lumen почти не тратит процессор.

## Установка

Скачай `Lumen-*.zip` со страницы [Releases](https://github.com/romankandeevy/lumen/releases), распакуй, перетащи в «Программы». Приложение не нотаризовано: при первом запуске — правый щелчок → «Открыть» → «Открыть».

Для подписки Claude нужен установленный [Claude Code](https://claude.com/code) 2.1.280 или новее (`claude update`), для ChatGPT — `npm install -g @openai/codex` и вход в Настройках.

## Сборка из исходников

```bash
./build.sh run
```

Нужен Xcode 27 или Command Line Tools.
- **Тесты:** `./build.sh test`.
- **Живые проверки** на настоящем `claude`, тратят немного лимита: `LUMEN_LIVE=1 ./build.sh test`.
- **Снимки экранов:** `LUMEN_SNAP=/папка swift test --filter snapshot`.
- **Снимки настоящего окна** с твоими данными: `open build/Lumen.app --env LUMEN_SELFSHOT=/папка`.

Рядом с Lumen в бандле лежит `lumen-mcp` — MCP-сервер памяти, навыков и вызова ботов, его запускают `claude` и `codex`.

Данные — в `~/Library/Application Support/Lumen`, навыки — в её папке `skills/`, ключ API — в Связке ключей. С чистого листа, не трогая свои данные: `open -n --env LUMEN_HOME=/tmp/lumen-test build/Lumen.app`.

Документы:
- как всё устроено и почему — `docs/tech-plan.md`;
- проверки `claude` — `docs/spikes.md`;
- версии — `docs/versions.md`;
- выпуск — `tools/release.sh` (проба: `tools/release.sh 1.0 --dry`).
