# Lumen

Mac-приложение по логике Hermes Agent, но красивое. Внешне — смесь Claude Code и Cursor.
Думает через подписку Claude Code или через Anthropic API. Codex и OpenAI подключим позже.

**Первая версия:**
- память между разговорами;
- понимание, с кем Lumen говорит (профили);
- настройка характера ответов;
- боты.

**Бот** — это тот же чат, только под одну задачу. У бота ровно один постоянный разговор: новый чат в нём не создаётся. Старое Lumen сжимает в пересказы, а важное кладёт в память.

Сейчас это **только макет** (React + Vite + shadcn), в нём нажимается каждая кнопка. Само приложение будет на Swift/SwiftUI, когда макет утвердят.

## Экраны макета

- **Знакомство** — при первом запуске: имя и обращение, через что думать, тема.
- **Чат** — шаги сворачиваются в одну строку. Под ответом подпись «Опирался на N воспоминаний». Плашка «Запомнил» с кнопками «Изменить» и «Забыть». Справа панель контекста: с кем говорю, память ответа, характер, окно контекста, расход.
- **Боты** — сверху в левой панели. У каждого один чат, прошлое свёрнуто в пересказы. Кнопки «Сжать сейчас» и «Сжимать само».
- **Память** — факты с источником: закрепить, изменить, забыть. Поиск по прошлым разговорам и файлы USER.md и MEMORY.md.
- **Люди** — профили собеседников: обращение, тон, что можно и что нельзя, своя память.
- **Характер** — тон, длина ответа, правила «всегда / никогда». Рядом живое превью и инструкции, которые получает модель.
- **Подключения** — подписка, ключ API, через что отвечать по умолчанию.
- **Настройки** — темы «Люмен» и «Монохром», «Меньше движения», горячие клавиши, данные.

Знак Lumen — светящаяся сфера. Когда он думает, сфера дышит, когда пишет — разгорается, когда запоминает — вспыхивает. Темы только тёмные.

## Макет

```bash
cd ui && npm install && npm run dev -- --port 5175
```

Открыть http://localhost:5175. Скриншоты лежат в `mockups/`. Знакомство показывается один раз; пройти его снова можно из «Настроек» или через ⌘K.
