# Что проверить в Lumen 1.1

Пиши номер пункта и что не так: «3 — браузер не открылся».

## Кастомизация
1. Внизу слева «Кастомизация», вкладки «Навыки · Коннекторы · Хуки». Твои навыки на месте.
2. Коннекторы → «Браузер (Playwright)» → «Подключить». Щёлкни по строке: появится список инструментов (первый раз ждать до минуты).
3. В обычном чате: «открой apple.com/ru и скажи заголовок страницы». Lumen делает это браузером.
4. Вставь в поле сверху `claude mcp add --transport http context7 https://mcp.context7.com/mcp` → «Добавить» → «Проверить» → «Сохранить».
5. «Найти в реестре MCP» → `notion` → «Подключить» открывает редактор.
6. Бот → «Изменить бота» → «Коннекторы»: отметь один. Он появится в паспорте бота.
7. Хуки → «Звук, когда ответ готов» → «Добавить». После ответа Lumen звучит «дзинь».

## Боты
8. Поле ввода бота: значок и «@имя» в цвете бота, «Своя папка ▾», «Средний ▾», без выбора модели.
9. Поменяй папку или «сколько думать» прямо в поле. Паспорт справа меняется сразу.
10. Позови `@designer задача` из обычного чата, потом открой бота. Там твоё сообщение с пометкой «из чата «…»», без простыни.
11. После ответа бота напиши Lumen в том же чате. Он отвечает без ошибки.

## Только ты можешь
12. Сделать копию ключа подписи обновлений, без неё следующие версии не выпустить:
    `cd ~/Documents/prog/lumen && .build/artifacts/sparkle/Sparkle/bin/generate_keys --account lumen -x ~/lumen-sparkle-key.txt`, файл убрать в надёжное место.
13. (По желанию) войти в ChatGPT: Настройки → Модели и оплата → «Войти через ChatGPT».
