# Что проверить в Lumen 1.1

Пиши номер пункта и что не так: «3 — бот не ответил».

## Боты
1. Поле ввода бота: значок и «@имя» в цвете бота, «Своя папка ▾», «Средний ▾», без выбора модели.
2. Поменяй папку или «сколько думать» прямо в поле. Паспорт справа меняется сразу.
3. Позови `@designer задача` из обычного чата, потом открой бота. Там твоё сообщение с пометкой «из чата «…»», без простыни.
4. После ответа бота напиши Lumen в том же чате. Он отвечает без ошибки.
5. Напиши просто `@designer` без текста — отвечает бот, а не Lumen. Со скриншотом — бот его видит.
6. Спроси Lumen «какие у тебя есть боты?» — перечисляет и подсказывает, как позвать.

## Запуск
7. Закрой Lumen (⌘Q) и открой снова. Окно появляется сразу, без вопроса про Связку ключей.

## Разговоры
8. Напиши Lumen длинную задачу, сразу открой «Новый чат» и напиши там. Оба отвечают; внизу плашка «Ещё отвечаю: «…»», щелчок — туда.
9. Наведи на своё сообщение: время, «Попробовать снова», «Изменить», «Копировать», «Глава». «Изменить» → поправь → «Отправить»: ответ ниже заменится, и Lumen не помнит старое.
10. Под ответом Lumen: «Копировать», «Попробовать снова», «Глава», время.
11. «Глава» у двух сообщений → справа сверху «Главы · 2» → щелчок по главе прокручивает к ней.
12. Попроси Lumen сделать MCP — текст до и после карточки идёт разными абзацами, карточка новая, аккуратная.

## Только ты можешь
13. Сделать копию ключа подписи обновлений, без неё следующие версии не выпустить:
    `cd ~/Documents/prog/lumen && .build/artifacts/sparkle/Sparkle/bin/generate_keys --account lumen -x ~/lumen-sparkle-key.txt`, файл убрать в надёжное место.
14. (По желанию) войти в ChatGPT: Настройки → Модели и оплата → «Войти через ChatGPT».
