# Что проверить в Lumen 1.1

Пиши номер пункта и что не так: «3 — браузер не открылся».

## Кастомизация
1. Коннекторы → щёлкни по строке «playwright». Под ней «25 инструментов» и список (было «не отвечает», починено).
2. В обычном чате: «открой apple.com/ru и скажи заголовок страницы». Lumen делает это браузером.
3. Вставь в поле сверху `claude mcp add --transport http context7 https://mcp.context7.com/mcp` → «Добавить» → «Проверить» → «Сохранить».
4. «Найти в реестре MCP» → `notion` → «Подключить» открывает редактор.
5. Бот → «Изменить бота» → «Коннекторы»: отметь один. Он появится в паспорте бота.
6. Хуки → «Звук, когда ответ готов» → «Добавить». После ответа Lumen звучит «дзинь».

## Боты
7. Поле ввода бота: значок и «@имя» в цвете бота, «Своя папка ▾», «Средний ▾», без выбора модели.
8. Поменяй папку или «сколько думать» прямо в поле. Паспорт справа меняется сразу.
9. Позови `@designer задача` из обычного чата, потом открой бота. Там твоё сообщение с пометкой «из чата «…»», без простыни.
10. После ответа бота напиши Lumen в том же чате. Он отвечает без ошибки.

## Запуск
11. Закрой Lumen (⌘Q) и открой снова. Окно появляется сразу, без вопроса про Связку ключей.

## Только ты можешь
12. Сделать копию ключа подписи обновлений, без неё следующие версии не выпустить:
    `cd ~/Documents/prog/lumen && .build/artifacts/sparkle/Sparkle/bin/generate_keys --account lumen -x ~/lumen-sparkle-key.txt`, файл убрать в надёжное место.
13. (По желанию) войти в ChatGPT: Настройки → Модели и оплата → «Войти через ChatGPT».
