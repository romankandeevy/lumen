# Что проверить в Lumen 0.9.20

Lumen уже открыт с этой версией. Если нет — `cd ~/Documents/prog/lumen && ./build.sh run`.
Отмечай галочки; что не так — пиши мне: что делал, что ждал, что увидел.

## 1. Вкладки наверху: Чат · Агент · Боты
- [ ] Вкладок три, «Боты» — третья. Внизу панели пункта «Боты» больше нет.
- [ ] В «Чате» нажми «Новый чат», перейди в «Агента» и вернись — снова пустой новый чат, а не последний.
- [ ] На вкладке «Боты»: «Создать бота», «Все боты», список ботов. Открой бота, уйди в чат, вернись — снова этот бот.

## 2. Поле ввода
- [ ] Поле ýже, чем было, и не меняется от «Настройки → Внешний вид → Ширина переписки».
- [ ] В левом нижнем углу «+»: прикрепи картинку и PDF — над текстом появятся превью и карточка файла, крестик убирает.
- [ ] Перетащи картинку из Finder прямо в поле — рамка подсветится, картинка прикрепится.
- [ ] Скопируй скриншот (⌘⇧⌃4) и вставь в поле ⌘V.
- [ ] Отправь картинку с вопросом «что на ней?» — в переписке картинка крупно, ответ про неё. Щелчок по картинке открывает её.
- [ ] Две-три картинки сразу — плиткой. Текстовый файл (.md, .swift) — Lumen читает его содержимое.

## 3. Агент
- [ ] Новая задача без выбора папки: Enter отправляет, работает во «Моих файлах» (шапка: «Агент во всех моих файлах»).
- [ ] Список папок в поле называется «Где работать», первым — «Мои файлы».
- [ ] Режимы в поле (Shift+Tab — следующий):
  - [ ] **Спрашивать** — попроси создать файл: появится «Можно?» с самим файлом; «Разрешить» (⌘↵) / «Отклонить» (Esc) работают.
  - [ ] **Принимать правки** — файлы правит сам, запуск кода спрашивает.
  - [ ] **План** — ничего не меняет, показывает «План готов — выполнить?»; «Выполнить · принимать правки» делает.
  - [ ] **Авто** и **Обход** — делают без вопросов. Push не проходит ни в одном.
- [ ] Настройки → Внешний вид → «Режимы агента в поле ввода»: выключи «Обход» — его нет в списке и Shift+Tab его пропускает.

## 4. Названия разговоров
- [ ] Новый чат после первого ответа получает нормальное название от модели (не первую фразу).
- [ ] Твои старые «привет» переименовались.

## 5. Навыки
- [ ] «Навыки» → «Каталог skills.sh»: рейтинг как на сайте — место, имя и репозиторий, линия за 8 недель, установки.
- [ ] Вкладки «За всё время (…)», «Тренды (24 ч)», «Горячее» переключаются.
- [ ] Поиск: напиши «pdf» — находятся навыки.
- [ ] Щелчок по строке раскрывает описание; «Поставить» при наведении. Поставь любой — в «Мои» он появится; второй раз — «уже стоит».
- [ ] «Создать навык» → «Написать с Lumen» — получается навык с описанием «когда брать» и шагами.

## 6. Панели
- [ ] Левую панель тяни за правый край — шире и уже; дальше половины окна не уходит.
- [ ] Правую (кнопка справа в шапке чата — «Контекст», у бота — паспорт) тяни за левый край — так же, до половины.

## 7. Остальное, что было до этого
- [ ] Граф памяти: «Память» → «Граф» — зум колесом, перетаскивание, двойной щелчок — окрестность.
- [ ] Бот: «Создать бота» → «Описать словами» → проверь права → «Создать». Позови в обычном чате: `@его-id задача`.
- [ ] Иконка в Dock — сфера (у тебя серая: в macOS включены тонированные иконки «графит»).
