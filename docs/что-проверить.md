# Что проверить в Lumen 1.1

Что не так — пиши мне: что делал, что ждал, что увидел.

## Кастомизация
- [ ] Внизу слева «Кастомизация», вкладки «Навыки · Коннекторы · Хуки». Твои навыки на месте.
- [ ] Коннекторы → «Браузер (Playwright)» → «Подключить». Щёлкни по строке: появится список инструментов (первый раз ждать до минуты).
- [ ] В обычном чате: «открой apple.com/ru и скажи заголовок страницы». Lumen делает это браузером.
- [ ] Вставь в поле сверху `claude mcp add --transport http context7 https://mcp.context7.com/mcp` → «Добавить» → «Проверить» → «Сохранить».
- [ ] «Найти в реестре MCP» → `notion` → «Подключить» открывает редактор.
- [ ] Бот → «Изменить бота» → «Коннекторы»: отметь один. Он появится в паспорте бота.
- [ ] Хуки → «Звук, когда ответ готов» → «Добавить». После ответа Lumen звучит «дзинь».

## Боты
- [ ] Поле ввода бота: значок и «@имя» в цвете бота, «Своя папка ▾», «Средний ▾», без выбора модели.
- [ ] Поменяй папку или «сколько думать» прямо в поле. Паспорт справа меняется сразу.
- [ ] Позови `@designer задача` из обычного чата, потом открой бота. Там твоё сообщение с пометкой «из чата «…»», без простыни.
- [ ] После ответа бота напиши Lumen в том же чате. Он отвечает без ошибки.

## Только ты можешь
- [ ] Сделать копию ключа подписи обновлений, без неё следующие версии не выпустить:
  `cd ~/Documents/prog/lumen && .build/artifacts/sparkle/Sparkle/bin/generate_keys --account lumen -x ~/lumen-sparkle-key.txt`, файл убрать в надёжное место.
- [ ] (По желанию) войти в ChatGPT: Настройки → Модели и оплата → «Войти через ChatGPT».
