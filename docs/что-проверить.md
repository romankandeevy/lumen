# Что проверить в Lumen 1.1

Пиши номер пункта и что не так: «3 — браузер не открылся».

## Кастомизация
1. Коннекторы → щёлкни по строке «playwright». Под ней «25 инструментов» и список (было «не отвечает», починено).
2. В обычном чате: «открой apple.com/ru и скажи заголовок страницы». Lumen делает это браузером.
3. Вставь в поле сверху `claude mcp add --transport http context7 https://mcp.context7.com/mcp` → «Добавить» → «Проверить» → «Сохранить».
4. Notion: у коннектора «mcp» нажми «Войти через браузер» (или удали его и заново: «Найти в реестре MCP» → `notion` → «Подключить», имя теперь «notion»). Войди в браузере, вернись — «N инструментов». Потом в чате: «найди в Notion мои заметки про …».
5. Бот → «Изменить бота» → «Коннекторы»: отметь один. Он появится в паспорте бота.
6. Хуки → «Звук, когда ответ готов» → «Добавить». После ответа Lumen звучит «дзинь».
7. В новом чате: «сделай мне MCP, который говорит погоду в Москве» (или любой свой). Под ответом карточка «Предлагаю коннектор…» с кодом → «Подключить» → в Кастомизации он есть и отвечает.
8. В чате: «найди коннектор для GitHub и предложи» — карточка с готовым; «сделай хук, чтобы звенело после ответа» — карточка «Добавить».

## Боты
9. Поле ввода бота: значок и «@имя» в цвете бота, «Своя папка ▾», «Средний ▾», без выбора модели.
10. Поменяй папку или «сколько думать» прямо в поле. Паспорт справа меняется сразу.
11. Позови `@designer задача` из обычного чата, потом открой бота. Там твоё сообщение с пометкой «из чата «…»», без простыни.
12. После ответа бота напиши Lumen в том же чате. Он отвечает без ошибки.

## Запуск
13. Закрой Lumen (⌘Q) и открой снова. Окно появляется сразу, без вопроса про Связку ключей.

## Разговоры
14. Напиши Lumen длинную задачу, сразу открой «Новый чат» и напиши там. Оба отвечают; внизу плашка «Ещё отвечаю: «…»», щелчок — туда.
15. Наведи на своё сообщение: время, «Попробовать снова», «Изменить», «Копировать», «Глава». «Изменить» → поправь → «Отправить»: ответ ниже заменится, и Lumen не помнит старое.
16. Под ответом Lumen: «Копировать», «Попробовать снова», «Глава», время.
17. «Глава» у двух сообщений → справа сверху «Главы · 2» → щелчок по главе прокручивает к ней.
18. Попроси Lumen сделать MCP — текст до и после карточки идёт разными абзацами, карточка новая, аккуратная.

## Только ты можешь
19. Сделать копию ключа подписи обновлений, без неё следующие версии не выпустить:
    `cd ~/Documents/prog/lumen && .build/artifacts/sparkle/Sparkle/bin/generate_keys --account lumen -x ~/lumen-sparkle-key.txt`, файл убрать в надёжное место.
20. (По желанию) войти в ChatGPT: Настройки → Модели и оплата → «Войти через ChatGPT».
