# Что проверить в Lumen 1.1 (в работе)

Lumen уже открыт с этой версией. Если нет — `cd ~/Documents/prog/lumen && ./build.sh run`.
Отмечай галочки; что не так — пиши мне: что делал, что ждал, что увидел.

## 00. Новое: Кастомизация (навыки + коннекторы + хуки)
- [ ] Внизу слева вместо «Навыки» — «Кастомизация». Вкладки «Навыки · Коннекторы · Хуки». Твои навыки на месте.
- [ ] «Папка» в шапке открывает customize/: там skills/, а после первого коннектора/хука — mcp.json и hooks.json (формат Claude Code).
- [ ] Коннекторы → «Готовые» → «Браузер (Playwright)» → «Подключить». Щёлкни по строке: «Что умеет» — список инструментов (первый раз npx качает до минуты).
- [ ] В обычном чате: «открой сайт apple.com/ru и скажи заголовок» — Lumen делает это браузером.
- [ ] Вставь в поле сверху строку из любого README, например `claude mcp add --transport http context7 https://mcp.context7.com/mcp` → «Добавить» → откроется редактор → «Проверить» → «Сохранить».
- [ ] «Найти в реестре MCP»: напиши `notion` или `postgres` — список, «Подключить» открывает редактор; токены вписываются в «Секреты» (уходят в Связку ключей, в файле — `${ИМЯ}`).
- [ ] Выключатель у коннектора: выключенный Lumen не видит.
- [ ] Бот → «Изменить бота» → «Коннекторы»: отметь один — у бота в паспорте появится раздел «Коннекторы». Без отметки бот коннекторов не видит.
- [ ] Хуки → «Звук, когда ответ готов» → «Добавить». Напиши Lumen что угодно — после ответа «дзинь».
- [ ] «Не давать удалять всё подряд» → «Добавить». Открой хук → «Проверить» — «Код 2 — остановит действие».
- [ ] «Новый хук»: событие из списка по-русски, команда, «Проверить» показывает код и вывод.
- [ ] Спроси Lumen «какие у тебя коннекторы?» — перечислит подключённые.

## 0. Было в 0.9.24 — по твоим замечаниям
- [ ] Боты → Дизайнер: в переписке больше нет простыней «Тебя позвали через @…». Там твоё обычное сообщение, а под ним мелкая пометка «из чата «…»». Щелчок по ней открывает тот чат.
- [ ] Позови `@designer задача` из обычного чата, потом открой бота: так же обычное сообщение с пометкой.
- [ ] Поле ввода бота: слева «+», знак и «@designer» в цвете бота, «Своя папка ▾», «Средний ▾». Рамка и кнопка отправки в цвете бота. Выбора модели нет (модель задаётся в паспорте).
- [ ] «Своя папка ▾» → «Мои файлы» или «Другая папка…»: в паспорте справа «Где работает» меняется сразу.
- [ ] «Средний ▾» → «Глубоко»: в паспорте тоже меняется.
- [ ] После ответа бота через @ напиши Lumen обычное сообщение в том же чате. Он отвечает, ошибки «завершился без ответа» нет.
- [ ] Если всё же ошибка: под ней «Повторить» отправляет заново, «Журнал» открывает лог.
- [ ] Чат через ключ API: «сделай себе навык …» работает.
- [ ] Выбери бота, уйди в «Агента», вернись в «Боты»: переписка на месте, без пустого экрана и подтормаживания.

## 3. Агент
- [ ] Новая задача без выбора папки: Enter отправляет, работает во «Моих файлах» (шапка: «Агент во всех моих файлах»).
- [ ] Список папок в поле называется «Где работать», первым — «Мои файлы».
- [ ] Режимы в поле (Shift+Tab — следующий):
  - [ ] **Спрашивать** — попроси создать файл: появится «Можно?» с самим файлом; «Разрешить» (⌘↵) / «Отклонить» (Esc) работают.
  - [ ] **Принимать правки** — файлы правит сам, запуск кода спрашивает.
  - [ ] **План** — ничего не меняет, показывает «План готов — выполнить?»; «Выполнить · принимать правки» делает.
  - [ ] **Авто** и **Обход** — делают без вопросов. Push не проходит ни в одном.
- [ ] Настройки → Внешний вид → «Режимы агента в поле ввода»: выключи «Обход» — его нет в списке и Shift+Tab его пропускает.
