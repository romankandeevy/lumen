# Версии Lumen и выкладка на GitHub

Lumen — проект с открытым кодом. Растёт по ступеням: каждая версия добавляет одну большую вещь, и по релизам видно, что проект живой и растёт.

## Правило выкладки

- На GitHub выкладываем **только стабильное**: версия проверена руками и прошла свой список проверок (ниже).
- Между релизами работаем локально. Коммитить можно сколько угодно, push и релиз — только когда версия готова.
- Номер: `0.МИНОР.ПАТЧ`.
  - **Минор** (0.1 → 0.2) — новая большая часть.
  - **Патч** (0.1.0 → 0.1.1) — исправления без новых возможностей.
  - **1.0** — когда всё из списка ниже работает вместе и стабильно.
- У каждого релиза: тег `v0.x.y`, заметки «что нового» простыми словами, скриншоты или короткое видео.

## Ступени

| Версия | Что добавляем | Проверить перед релизом |
|---|---|---|
| **0.1 — Чат** | Чат: модель, «сколько думать», стрим и «Стоп». Правая панель: окно контекста, лимиты подписки, расход API. Вход: подписка Claude Code или ключ API. Знакомство, темы, ширина переписки | 20 настоящих разговоров. «Стоп» быстрее 0,5 с. Без сети и без ключа — понятные ошибки. Лимиты совпадают с claude.ai |
| **0.2 — Агент** | Вкладка «Агент»: папка, шаги, карточка «Изменения» (разница, откатить, закоммитить), push только с OK, план сбоку, песочница (браузер, превью сайта, видео, 3D, файлы), карточка «что дальше» | Правка в настоящем проекте, откат, коммит. Push без OK невозможен. Песочница открывает localhost |
| **0.3 — Память** | Факты с источником, «Запомнил», «Опирался на», закрепить, изменить, забыть, поиск по прошлым разговорам, граф | Факт из одного чата всплывает в другом. «падение» находит «падал Shelf» |
| **0.4 — Люди и Характер** | Анкеты людей, характер (SOUL), живое превью | Тон и правила реально меняют ответы. Сведения о людях учитываются |
| **0.5 — Инструменты** | Навыки (каталог, «уже скачано — не качать»), MCP, 20 коннекторов + свой коннектор | Коннектор подключается через браузер. Навык ставится один раз |
| **0.6 — Боты** | Боты-субагенты, вызов через @, «отрезано в коде», один чат со сжатием, конструктор, самонастройка | @tester не может изменить файл ни правкой, ни командой. Вне роли — отказ и передача другому |
| **0.7 — Голос** | Голосовой разговор, перебивание, камера и экран | Перебивание быстрее 0,5 с. Эхо не принимается за речь |
| **0.8 — Группы ботов** | Роли, общий план, очередь слова, замки на файлы, вопросы Роме | Группа доводит небольшую задачу до конца без конфликтов в файлах |
| **0.9 — Облако и другие модели** | Облако через API (Managed Agents), Codex и OpenAI | Облачная сессия видна по шагам. Смена провайдера не ломает чат |
| **1.0** | Всё вместе, стабильно, с установщиком и автообновлением | Неделя живого пользования без падений |
