# Версии Lumen и выкладка на GitHub

Lumen — проект с открытым кодом. Растёт по ступеням: первый публичный релиз 1.0 уже полноценный, дальше видимый рост через 1.1, 1.2 … и большие скачки 2.0, 3.0.

## Как нумеруем

| Вид | Номер | Что это | На GitHub |
|---|---|---|---|
| **Стабильная** | `1.0`, `1.1`, `1.2` … (тег `v1.1.0`) | Новая часть целиком, проверена руками по списку ниже | Релиз с пометкой **Latest** — это то, что скачивают по умолчанию |
| **Бета** | `1.0.1`, `1.0.2` … (тег `v1.0.1`) | Всё между стабильными: фиксы, куски новых функций, правки. Может быть нестабильной | Релиз с пометкой **Pre-release** |
| **Любой коммит** | — | Каждая правка | Коммит в `main`, собрать можно из исходников |

- Бета-версии 1.0.1, 1.0.2 … ведут к следующей стабильной **1.1**. После 1.1 начинаются 1.1.1, 1.1.2 … и так далее.
- Большой скачок (новая крупная часть, например боты) — **2.0**.

## Правило выкладки

- **Коммитим почти после каждой правки и часто отправляем на GitHub.** История видна полностью.
- **Бету** выпускаем, когда набралось заметное изменение и оно собирается и запускается.
- **Стабильную** — только после проверки руками по списку ступени (таблица ниже).
- **Что скачивается:**
  - По умолчанию — последняя стабильная: ссылка «Скачать» в README ведёт на Latest, автообновление (Sparkle) по умолчанию на стабильном канале.
  - В настройках Lumen можно включить канал «Бета» — тогда приходят и пререлизы.
  - Любую версию можно скачать со страницы Releases, любой коммит — собрать из исходников (в README будет инструкция).
- У каждого релиза: тег, заметки «что нового» простыми словами, скриншоты или короткое видео.

## Ступени

До 1.0 — внутренние сборки (неделя проверок из §12 техплана и работа до 1.0), наружу номера 0.x не показываем.

| Версия | Что добавляем | Проверить перед стабильным релизом |
|---|---|---|
| **1.0 — Чат, Агент, Память** | Чат: модели, «сколько думать», стрим, «Стоп». Правая панель: контекст, лимиты, расход. Вход: подписка или ключ API, знакомство, темы, ширина переписки. Агент: папка, шаги, «Изменения» (разница, откатить, закоммитить), push только с OK, план сбоку, «что дальше», показ на острове. Память: «Запомнил», «Опирался на», закрепить, изменить, забыть | 20 настоящих разговоров. «Стоп» быстрее 0,5 с. Правка и коммит в настоящем проекте, push без OK невозможен. Факт из одного чата всплывает в другом. Без сети и без ключа — понятные ошибки |
| **1.1 — Граф и прошлые разговоры** | Граф памяти как в Obsidian, поиск по разговорам с русскими окончаниями | «падение» находит «падал Shelf». Граф не тормозит на 1000 фактах |
| **1.2 — Люди** | Анкеты о близких, Lumen учитывает их в разговоре | Факт о человеке всплывает, когда о нём говоришь |
| **1.3 — Характер** | Все настройки, живое превью настоящей моделью | Тон и правила реально меняют ответы |
| **1.4 — Песочница** | Превью сайта, браузер, видео, 3D, файлы — сбоку | Агент открывает свой localhost, видео и USDZ показываются |
| **1.5 — Навыки** | Каталог, установка, «уже скачано — не качать», создание своих | Навык ставится один раз, работает в разговоре |
| **1.6 — Коннекторы и MCP** | 20 популярных коннекторов + свои, MCP-серверы, внешние API | Коннектор подключается через браузер, ключи в Связке ключей |
| **1.7 — Голос** | Голосовой разговор: два потока распознавания (FlowLocal), локальная нейро-озвучка, перебивание | Перебивание быстрее 0,5 с, эхо не принимается за речь |
| **1.8 — Камера и экран** | Камера MacBook или iPhone и экран в голосовом режиме | Lumen верно описывает показанное, старые кадры не копятся |
| **2.0 — Боты** | Вкладка «Боты», вызов через @, «отрезано в коде», один чат со сжатием, конструктор, самонастройка с навыками | @tester не может изменить файл ни правкой, ни командой. Вне роли — отказ и передача другому |

| **2.2 — Группы ботов** | Роли, общий план, очередь слова, замки на файлы, вопросы Роме | Группа доводит задачу до конца без конфликтов в файлах |
| **2.3 — Облако через API** | Managed Agents: видно каждый шаг, Мак можно закрыть | Облачная задача видна по шагам, тратит кредиты API |
