## 9. Как снимать (если нужно ещё)

Встроенный браузер Lumen/Claude выходит из аккаунта → снимать через Claude in Chrome (вход у Ромы есть). Окно 1470 CSS-px (скриншот ужат до 1383 — клики по координатам
кадра снимка, множитель 1.063). Меню Radix открывать настоящим кликом. Ничего не отправлять, не менять настройки, окна «Войдите снова» / «Включить уведомления» закрывать
«Не сейчас». После каждой навигации заново вставлять helper-функции `__s(el)`, `__byText(t)`, `__up(el)` (код — в истории этой сессии / `redesign.md`, раздел 10: размер, шрифт, вес из
`font-variation-settings`, pad, radius, рамка, фон, gap, альфа). Скриншоты копировать в `build/claude-shots/web/NN-имя.jpg`. В конце — закрыть вкладки и сбросить размер окна.
