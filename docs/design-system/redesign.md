# Дизайн-система Claude (новый дизайн «fizzy_lake») — для переноса в Lumen

Снято 26.10.2026 с claude.ai (веб = то же, что приложение Claude) во встроенном браузере Lumen. Цвета НЕ переносим:
у Lumen свои темы (Люмен, Монохром, Корона, Сияние, `Palette` в Theme.swift). Переносим шрифтовые роли, размеры, отступы,
радиусы, иконки, вёрстку, движение.

Проверка включённого дизайна: на `<html>` стоит `data-cds-fizzy-lake="color icons panels type"` (из localStorage
`spa:fizzy-lake`). На странице `claude.ai/code` атрибут появляется не сразу — мерить на `claude.ai/new`.

Что в этом файле подтверждено замером (browser_js, `getComputedStyle`), а что ещё не снято — см. раздел «Не снято».
Исходный план и приёмы: `HANDOFF.md` рядом.

## 1. Шрифты

| Роль в Claude | Шрифт Claude (закрытый) | Что берём в Lumen |
|---|---|---|
| Интерфейс | anthropic-sans | SF Pro (системный) |
| Ответы | настройка «Шрифт ответов»: по умолчанию serif, «Как в интерфейсе» = sans | выбор: как в интерфейсе (SF Pro) / с засечками (New York или Georgia) |
| Заголовки страниц, приветствие | anthropic-serif | New York / Georgia |
| Код | anthropic-mono | SF Mono |

Anthropic Sans/Serif/Mono и иконки Anthropicons закрыты — в публичный репозиторий не копировать, только метрики.
В них нет кириллицы, поэтому русский Claude на деле рисуется системными шрифтами; SF Pro + Georgia/New York + SF Mono
выглядят так же. Режим «Как в системе» (`data-system-font`) у Claude ставит `--font-anthropic-mono: "SF Mono", ui-monospace, Menlo`.
Шрифт для дислексии (OpenDyslexic) — отдельная настройка, у нас не нужен.

### Веса (variable-шрифт, значения `--cds-font-weight-*`)

| Токен | Вес | Где |
|---|---|---|
| body | 400 | обычный текст |
| control | 435 | кнопки, меню, навигация, заголовок чата |
| header | 520 | заголовки разделов, диалогов, подписи групп |
| badge | 540 | бейджи |
| medium / semibold / bold | 500 / 580 / 600 | таблицы (th 500), общие утилиты |
| strong в ответе | 501 | жирное в тексте ответа |
| приветствие | 330 | serif 38 на главной |

У Lumen (SF Pro) веса дискретные: 400 → `.regular`, 435 → `.medium` (чуть светлее — допустимо `.regular` + 0,2 pt к размеру
не нужно, берём `.medium`), 520 → `.semibold` (или `.medium`, если выглядит тяжело), 501 → `.semibold`.

## 4. Отступы, высоты, радиусы (токены Claude → значения)

Высоты контролов (`--cds-h-control`): xs 24 · sm 28 · по умолчанию 28 · lg 40. Вложенные (`-nested`): 18 / 20 / 22 / 28.
В компактной плотности (`data-density=compact`) xs 20, sm 20, lg 28.
Паддинги (`--cds-pad-*`): xs 6, sm 8, md 12, lg 16, xl 24; у размеров `--xs/--sm/--lg` на ступень меньше/больше
(например md: 8 / 10 / 12 / 16, lg: 12 / 14 / 16 / 20).
Зазоры (`--cds-gap-*`): xs 8, sm 12, md 16, lg 28, xl 40.
Радиусы (`--cds-radius*`): xs 6, sm 7, base 8, lg 10; поле ввода (`--cds-radius-composer`) 14 (на экране ~20 с рамкой);
меню 14, диалог 12, пузырь человека 12, кнопка 6–8, сегменты 6, окно настроек 12, круглые — 50%.
Высота строки списка (`--list-row-h`): 32 (comfortable). Шаг между строками сайдбара (`--df-row-gap`) 4.
Кнопка шага (`data-step` 1…5): высота 20 / 24 / 28 / 28 / 40, паддинг 6 / 8 / 9 / 9 / 16 px.

Для Lumen вместо `R.sm…xxxl` (7.2/9.6/12/16.8/21.6/26.4) — шкала Claude: 6, 8, 12, 14, 20, круг. Старые числа — не
использовать, менять вызовы по ролям: кнопка/сегмент 6–8, карточка/пузырь/диалог 12, меню/поле ввода 14–20.

## 6. Движение (токены)

| Токен | Значение | Для чего |
|---|---|---|
| `--cds-dur-fast` | 60 мс | мгновенные реакции (нажатие) |
| `--cds-dur-snap` | 120 мс | быстрые переходы, наведение |
| `--cds-dur-base` | 200 мс | обычное |
| `--cds-dur-sheet` | 300 мс | панели, листы |
| `--cds-dur-slow` | 450 мс | крупные появления |
| `--cds-ease-out` | cubic-bezier(.165, .84, .44, 1) | мягкое замедление, основное |

| `--cds-ease-overshoot` | cubic-bezier(.34, 1.3, .64, 1) | лёгкий перелёт, появление мелочей |
| `--df-ease-out-cubic` | cubic-bezier(.215, .61, .355, 1) | рамка окна / сайдбар |

Точка статуса («clay») пульсирует: 2.4 с, ease-in-out, бесконечно. Появление подсказки в поле ввода — с задержкой 2 с

обычным SwiftUI-движением.
Для Lumen: `Motion.fast/snap/base/sheet/slow` + кривые `.timingCurve(...)` по таблице; учитывать «Уменьшить движение».
