# Lumen 1.3.2

- Картинки агента в ответе — как в Claude Code: маленькие превью в строку, при наведении — крупнее, много — первые четыре и «+N». Раньше была огромная сетка.
- Твои сообщения больше не прижаты к правому краю окна: пузырь стоит по колонке переписки. Поля по бокам шире.
- «Идёт в Claude Code» — только когда там правда идёт ход (по записям сессии, а не по времени файла); нет связи с API — так и написано.
- Ошибка API из Claude Code — красной ошибкой под ответом, а не текстом.
