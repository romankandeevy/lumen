# Lumen 1.3.8 — Характер

- «Характер» в левой панели: имя и «кто он», тон, длина ответов, язык, юмор, оформление, эмодзи, запрещённые слова, самостоятельность, честность, рассуждения, подсказки о висящем, правила «Всегда» и «Никогда».
- Справа — живое превью: тот же вопрос, отвечает настоящая модель (Haiku) с этими настройками, через секунду после правки.
- «Показать инструкции, которые получает модель» — итоговый текст характера.
- Сохранённый характер действует со следующего ответа во всех чатах и задачах агента, даже посреди разговора; идущий ответ не обрывается. У ботов — свой характер из конструктора.
