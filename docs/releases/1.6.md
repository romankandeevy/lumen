# Lumen 1.6 — затмение, окно настроек, файлы и источники

Стабильная. Новый облик (знак-затмение, небо, темы), настройки отдельным окном, у файлов сбоку — своё превью, под ответами — источники, из «+» можно взять репозиторий GitHub. В неё вошло и всё из бет 1.5.1 и 1.5.2.

### Облик

- Вместо шара — знак-затмение: корона, лучи, свет по кругу, пока Lumen думает. Небо со звёздами и лучами из центра знака; цвета короны и лучей — по теме.
- Темы: «Тёмная», «Светлая», «Как в системе»; выбор темы относится к своему свету. Светлая тема заново по макету, поле ввода сплошное.
- Шапка по макету: название по центру (в проекте — «Проект / Чат»), справа фоновые задачи, браузер, панель и «⋯». Верх переписки растворяется под шапкой, без плашки.
- Ответ — настоящий markdown: заголовки, списки, цитаты, линии. Текст между блоками кода выделяется одним полем.
- Пузырь человека мягче, ответ стоит ровно по левому краю поля ввода. «Запускаю…» вместо «Думаю…», пока поднимается claude.
- Граф памяти: узлы-темы вместо лучей из «ты», «ты» — маленькое затмение.
- «Запомнил N фактов» — одна сворачиваемая плашка.

### Настройки — отдельное окно

- Настройки открываются окном поверх главного, а не страницей вместо чата: чат остаётся на месте, окно двигается и тянется, помнит размер и место, закрывается Esc или ⌘W.

### Файлы сбоку

- У каждого вида файла своё превью, как у Claude: markdown оформленным текстом, код и текст моноширинным, PDF, картинки, видео, звук; презентации, документы, таблицы и 3D-модели — через системный Quick Look. Страницы остаются в браузере.
- Цитату из файла сбоку можно отправить в поле ввода.
- Файлы лежат в тексте сообщения карточками: после карточки пишешь правку, потом следующий файл. Стёр карточку ⌫ — вложение уходит вместе с ней.

### Источники ответа

- Под ответом — строка «Источники» с чипами: значок сайта и домен. В тексте у ссылок такие же маленькие номера. Нажатие открывает страницу сбоку.
- Если изменить вопрос, прежний ответ не пропадает: он остаётся вариантом нового (‹ 1/2 ›).

### Поле ввода и «+»

- «Поиск в сети» и «Память о тебе» — в меню «+». Выключил поиск — у чата нет инструментов сети; выключил память — Lumen не читает и не записывает факты.
- «Ресерч» на следующее сообщение: глубокое исследование вместо обычного ответа; после отправки сам выключается. Рядом с «+» — только то, что включено в этом сообщении.
- «Добавить из GitHub»: вставь `owner/repo` или ссылку — репозиторий клонируется в папку Lumen (мелко, без истории). Агент получает его папку с доступом, чат — README и структуру вложениями. Есть список твоих репозиториев.
- Чипы бота и навыка внутри текста; в узкой области кнопки под полем встают в два ряда.

### Агент

- Снимки экрана, сделанные на шагах, — превью на строке шага (до трёх и «+N»); нажатие открывает снимок.
- Новая задача: «Что сделаем в {папка}?», имя папки открывает выбор; «Режим» вместо «Обход»/«Ночь»; «Включить git».

### Из бет 1.5.1 и 1.5.2

- Питомцы и капли ботов, раздельные проекты чата, агента и ботов.
- Агент работает сам: «Ночь», «спрашивать, только когда я рядом», страж готовности, своё сжатие разговора, автовыбор модели.
- Фоновые задачи агента списком: субагенты, исследования, команды с живым выводом.
- Сторож больше не прерывает идущие команды; прокрутка шагов отдельно и без «резинки».
