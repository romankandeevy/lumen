# Lumen 1.0 — Чат, Агент, Память

Первая публичная версия. Lumen — приложение для Mac, через которое удобно разговаривать с Claude и давать ему задачи в папках проектов. Всё хранится на этом Маке.

## Что умеет

**Чат**
- Модели Claude и «сколько думать», ответ появляется по мере написания, «Стоп» останавливает сразу.
- Через подписку Claude (нужен установленный `claude`) или через свой ключ API — можно держать оба.
- Справа — контекст разговора, лимиты подписки и расход по API. Месячный лимит трат по API.
- Проекты: свои инструкции и файлы, которые Lumen учитывает в каждом разговоре проекта.
- Поиск по всем разговорам (⌘K), закреп, переименование, свои меню с буквами-клавишами.
- Подсказки на пустом экране Lumen придумывает сам по твоим недавним разговорам.

**Агент**
- Работает в выбранной папке: читает, правит, запускает команды. Шаги видно по ходу.
- План сбоку и «что дальше» в конце.
- «Изменения»: разница по файлам, откатить (в Корзину), закоммитить. Отправка на GitHub (push) — только с твоего OK.

**Память**
- Lumen сам запоминает важное («Запомнил») и опирается на это в других чатах («Опирался на»).
- Страница «Что Lumen знает»: закрепить, изменить, забыть, вернуть.

**Ещё**
- Две темы (Люмен и Монохром), ширина переписки, живой фон в чате, «Меньше движения».
- Автообновление: стабильные версии по умолчанию, бета — по желанию в Настройках → Обновления.

## Установка

Скачай `Lumen-1.0.zip`, распакуй и перетащи Lumen в «Программы». Приложение не нотаризовано, поэтому при первом запуске: правый щелчок по Lumen → «Открыть» → «Открыть».
