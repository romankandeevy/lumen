- **Память между чатами** — факт из одного чата всплывает в другом.

  - бот без права правки не меняет файл ни правкой, ни командой;

## Что осталось тебе — один разговор

Открой Lumen и поговори с ним, как обычно. Примерно 20 сообщений вперемешку:

1. **Чат.** Что-нибудь живое: «Что поделаем сегодня?», вопрос по проекту. Посмотри, как печатается ответ. Посреди длинного ответа нажми «Стоп».
2. **Память.** Скажи «Запомни, что …» — появится «Запомнил». Открой новый чат и спроси об этом — должно быть «Опирался на».
3. **Агент.** Вкладка «Агент» → папка любого проекта → маленькая правка → «Изменения» → «Закоммитить». Попроси сделать push — откажет.
4. **Бот.** «Боты» → «Создать бота» → «Описать словами» (например, «бот, который проверяет сборки») → проверь права → «Создать». Потом в обычном чате: `@его-id задача`.
5. **Навык.** «Навыки» → «Каталог Anthropic» → поставь любой. Или «Создать навык» → «Написать с Lumen».
6. **Глазами.** Граф памяти, поиск ⌘K, меню «…», обе темы.

Если всё ок — скажи «выпускай», и я выпущу 1.0.

## Что можно сделать только тебе

- **Ключ API.** Если хочешь проверить чат по ключу: Настройки → Модели и оплата → вставить ключ → «Проверить».
- **ChatGPT.** Настройки → Модели и оплата → «Войти через ChatGPT» (откроется браузер).
- **Резервная копия ключа подписи обновлений.** Без него обновления не выпустить:
  `.build/artifacts/sparkle/Sparkle/bin/generate_keys --account lumen -x ~/lumen-sparkle-key.txt` — файл убрать в надёжное место.
- **Доступ к Связке ключей.** При первом настоящем выпуске macOS спросит, можно ли `sign_update` брать ключ из Связки ключей, — нажать «Разрешать всегда».

## Выпуск

```bash
tools/release.sh 1.0
```

Скрипт:
1. ставит номер версии;
2. собирает приложение;
3. подписывает обновление;
4. дописывает ленту обновлений;
5. коммитит и ставит тег `v1.0.0`;
6. отправляет на GitHub и создаёт релиз Latest.

Бета после 1.0: `tools/release.sh 1.0.1 beta`.

- **Нотаризации.** Нужен платный Apple Developer ID ($99 в год). Без неё при первом запуске скачанного Lumen нужно «правый щелчок → Открыть».
