# Перед выпуском 1.0 — что проверить руками

Всё, что можно было сделать без Ромы, готово: автообновление встроено, лента `appcast.xml` лежит в репозитории, ключ подписи обновлений создан, скрипт выпуска `tools/release.sh` и заметки `docs/releases/1.0.md` написаны. Ниже — то, что может проверить только человек (список из docs/versions.md).

## Проверки ступени 1.0

- [ ] 20 настоящих разговоров в чате (подписка), без падений и зависаний.
- [ ] «Стоп» останавливает ответ быстрее 0,5 с (на глаз — сразу).
- [ ] Агент: правка и коммит в настоящем проекте. Попросить сделать push — должен отказаться без OK.
- [ ] Факт из одного чата всплывает в другом («Опирался на»).
- [ ] Без сети — понятная ошибка. С неверным ключом API — понятная ошибка.
- [ ] Ключ API: вставить настоящий ключ, «Проверить», один разговор через API (у меня проверено только на записанных ответах).
- [ ] Окно глазами: сайдбар, меню «…», поиск ⌘K, настройки, тёмная и монохромная темы.

## Перед первым выпуском

- [ ] `claude update` — чтобы появился Opus 5.5 (нужна версия claude ≥ 2.1.280).
- [ ] Ключ подписи обновлений лежит в Связке ключей (запись `lumen`, создана 16.10.2026). Сделать резервную копию:
      `.build/artifacts/sparkle/Sparkle/bin/generate_keys --account lumen -x ~/lumen-sparkle-key.txt` — и убрать файл в надёжное место. Без этого ключа обновления выпускать нельзя.
- [ ] При первом `tools/release.sh` macOS спросит доступ `sign_update` к Связке ключей — «Разрешать всегда».
- [ ] Поправить заметки `docs/releases/1.0.md`, если что-то хочется сказать иначе; приложить скриншоты.

## Выпуск

```bash
tools/release.sh 1.0
```

Скрипт сам поставит номер, соберёт, подпишет обновление, допишет ленту, закоммитит, поставит тег `v1.0.0`, отправит на GitHub и создаст релиз Latest.

Бета после 1.0: `tools/release.sh 1.0.1 beta`.

## Чего нет и почему

- **Нотаризации.** Нужен платный Apple Developer ID ($99 в год). Без неё при первом запуске скачанного Lumen нужно «правый щелчок → Открыть». Когда появится Developer ID — добавить в `build.sh` подпись им с Hardened Runtime и `xcrun notarytool submit`.
