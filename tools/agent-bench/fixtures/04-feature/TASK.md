Добавь в todo.py две вещи:
1. `python3 todo.py done <id>` — отметить дело сделанным. Несуществующий id — понятная ошибка и код выхода 1.
2. `python3 todo.py list --json` — список в JSON (как в todo.json). Обычный `list` показывает сделанные как «1. [x] текст», несделанные — «2. [ ] текст».
