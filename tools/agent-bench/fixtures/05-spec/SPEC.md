# mdtable — выравнивание таблиц Markdown

Модуль `mdtable.py` с функцией `format_table(text: str) -> str`.

На входе — текст таблицы Markdown (строки вида `| a | b |`, вторая строка — разделитель `|---|:--:|---:|`).
На выходе — та же таблица, выровненная по колонкам:

1. Каждая ячейка дополнена пробелами до ширины самой широкой ячейки своей колонки; вокруг текста ячейки ровно по одному пробелу: `| текст   |`.
2. Ширина считается в видимых символах: кириллица и латиница — по одному, эмодзи и иероглифы (East Asian Wide/Fullwidth) — по два.
3. Выравнивание из строки-разделителя: `:---` или `---` — влево, `:---:` — по центру (лишний пробел, если не делится поровну, — справа), `---:` — вправо. Строка-разделитель после форматирования — из дефисов на всю ширину колонки, двоеточия сохраняются на своих местах (`:----:`).
4. Экранированная черта `\|` внутри ячейки — часть текста, а не граница (и считается за 2 символа, как написана).
5. Строки короче остальных дополняются пустыми ячейками; лишние ячейки — новые колонки (выравнивание — влево).
6. Пробелы в начале и конце ячеек отбрасываются; пустые строки до и после таблицы — тоже. Конец строки — `\n`, в конце результата `\n` нет.
7. Не таблица (нет строки-разделителя второй строкой) — `ValueError` с понятным сообщением.
8. Ширина колонки — не меньше 3 (чтобы разделитель был хотя бы `---`).

Плюс командная строка: `python3 mdtable.py < table.md` печатает выровненную таблицу; ошибка — сообщение в stderr и код выхода 1.

Нужны тесты на все пункты.
